# Service Knowledge Bot

Архитектура прототипа Telegram-бота сервисного отдела компании «Канализация Загород».

На текущем этапе репозиторий содержит только проектную документацию: код будет добавлен отдельным этапом после согласования архитектуры.

## Цель

Бот отвечает клиентам только на основании утверждённой базы знаний. Если подходящей информации нет, бот не генерирует инструкцию, а сообщает об этом и передаёт вопрос в сервисный отдел.

## Обязательные сценарии MVP

1. Обслуживание станции КАН Ультра — ссылка на видеоинструкцию.
2. Обслуживание станции КИТ — один раз в год.
3. Переполненная станция — проверка электрического блока, обесточивание и обращение в сервисный отдел при затоплении.
4. Неизвестный вопрос — безопасный отказ без выдуманного ответа.

## Принцип безопасности ответов

Генерация произвольного ответа не является частью MVP. Система возвращает только текст утверждённой статьи, найденной в базе знаний при достаточной уверенности. В противном случае используется сценарий эскалации.
